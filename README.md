# ⛏️ Tambang Kaya

Idle clicker game bertema tambang. Dibangun dengan vanilla JS, dihosting di Vercel, database di Supabase.

## Stack
- **Frontend:** HTML + CSS + Vanilla JS (ES Modules)
- **Hosting:** Vercel
- **Database:** Supabase (PostgreSQL)
- **Repo:** GitHub
